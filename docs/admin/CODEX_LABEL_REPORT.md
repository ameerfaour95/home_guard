# Home Guard Admin — Label view

Implemented on `admin-label-ui`, entirely in this temporary worktree. No push, SSH, AWS access, or changes to `home_guard_project/cloud/` or `home_guard_project/fleet_contract/`.

## Delivered

- Label workspace reached from admin/labeler event views, the navigation rail, and Studio's Needs labeling / To review / Rejected filters. Labelers land directly in the labeling queue.
- Native decoded video with normalized, clamped rectangles, eight resize handles, a four-native-pixel minimum, theme-derived class colors, class chips, dashed suggestions, and Accept all suggestions. Editing a suggestion converts it to human.
- Shared `fleet_contract.tracks` interpolation and validation. Enabled boundaries hold/interpolate by time; disabled boundaries hide the segment. The timeline supports per-track selection, keyframe dragging, seeking, and Keep/Hide context actions.
- All requested shortcuts and keyboard help. Text fields retain ordinary typing; global save, submit, undo and redo remain available. Undo/redo includes text, flags, tracks, class changes and keyframes.
- Read-only AI draft and editable human description, change marker, drop/review flags, admin model/prompt-version metadata, and admin Accept/Reject with note and frame. Labeler views expose neither prompt metadata nor raw records.
- Two-second debounced draft saving, explicit saving, save before clip switch, submitted status with queue advancement, complete local edit history, and version history. Saves send `base_version`; conflicts stop autosave and offer Reload or Keep mine against a newly fetched base. Later edits survive an in-flight save acknowledgement.
- Annotation status chips in timeline/review rows and Studio collection grids. Saved annotations update already-loaded event rows.
- Admin collection publishing with a suggested site batch name, slug validation, labeled/not-labeled/dropped counts, the requested Label Studio layout explanation, and the publish POST. Tagging batches list states, task/YOLO/VLM counts, scrollable missing items, and Copy S3 path; it refreshes while visible.
- Typed desktop models and backend methods matching contract 2f. Demo annotations, versions, reviews, and publishes remain in memory; YOLO suggestions use `tracks_from_weak_labels`.

## Important decoding detail

The editor uses `QVideoSink` presentation timestamps for displayed frames and newly edited keyframes. Native frame stepping seeks inside the frame interval: Qt's paused decoder may return the preceding frame when seeking exactly at an inclusive end boundary. While a seek is pending, drawing is disabled and stale decoded frames are ignored. Playback uses QMediaPlayer's real-time clock. Unobserved frame times use the contract's `frame_time` helper and the clip/decoder FPS, as specified.
